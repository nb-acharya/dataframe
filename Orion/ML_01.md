## Hands on Machine Learning with scikit learn, keras and tensorflow

Machine Learning: computer learning based on the given data and predict the result for the new data.

- it should learn from given data
- ML is the field of study that gives computers the ability to learn without being explicitly programmed.
- training set: examples system is using to learn. Each training example is called training instance or sample.

Supervised Learning: The training set that we feed to the algorithm includes the desired solutions called labels.   
Unsupervised Learning: The training data is unlabeled. the system tries to learn without a teacher.

Dimensionality reduction, Feature extraction. if there are two or more features that are correlated, then merge several correlated features into one.


### pipeline
Data pipeline is a sequence of data processing components.
we have lot of component and one output of the component will be the input to next component. And even if the component one breaks, it can still give out the last output from the broken component to the downstream components.
